# Security Policy

If you believe you've found a security vulnerability in terragraph, please **do not** open a public issue for it.

Instead, use GitHub's private reporting: go to the [Security tab](https://github.com/cloudfluent/terragraph/security) and click "Report a vulnerability". This opens a private advisory visible only to the maintainers until a fix is ready.

We'll acknowledge a report within a few days and keep you updated as we work on a fix.
